# Company and Firestopping settings

Application Settings is available from the main navigation. Save company name,
ABN, phone, email and a PNG/JPEG logo there. These preferences live in the existing
application preferences table and apply to subsequent PDF downloads. They do not
change saved project calculations or pricing. The logo limit is 2 MB and four
million pixels; invalid uploads leave the saved settings intact.

Authored estimates, calculator schedules and summaries, Firestopping schedules,
item details, technical items and passive fire matrices share Ceasefire red,
black, white and neutral greys, regardless of the browser theme. Takeoff legend
branding uses the same colours and company details. Original drawing pages,
source diagrams, uploaded logos and user-selected markup colours retain their
own pixels and meaning.

Firestopping Settings includes seven Details dropdown lists, edited using
semicolon-separated values. They are stored with the Firestopping project
settings. Removing a choice does not rewrite an existing item: its saved value
remains visible until the user chooses a replacement. Changing these lists does
not change the service routing or workbook formulas.

Fresh Firestopping drafts start with 30% for each material waste setting and
board/bulkhead multipliers of 2. Choosing Vertical or Horizontal supplies blank
wrap/collar multipliers with 2 or 1 respectively. Existing entered multipliers,
saved waste values and the legacy interpretation of omitted waste settings are
retained. Mastic Type and a positive Mastic Qty are required together for new
entries; incomplete pairs receive a specific correction message.

Clear asks Yes/Cancel before clearing the current item calculator. The schedule
and project settings retain their existing scope. Calculator save state appears
as a compact yellow tag. Firestopping breakdowns show useful correction messages
and `Check inputs` in unavailable cells; raw calculation results remain intact.

The Takeoffs navigation and Home card use the original floor-plan and pencil SVG.
The Measure control retains the supplied AVIF asset. Pricing Add item is beside
Document and moves focus to the new row. Both Firestopping Add controls reuse the
Steel schedule button styling.
