# Technical catalog product decisions

The Technical Library has a public catalog projection after source configuration and duplicate reviews. Original imported records, assets and review fingerprints remain intact. Public listing, details, filters and reference resolution consume the same projected records.

The explicit Trafalgar product families FyreSHIELD, FyreSHIELD PLUS and their screw-fixed variants reference **FAS200221 R3.0**, linked to `https://tfire.com.au/documents/FyreSHIELD-Range-Test-Report`. The supplier report cover identifies that report and revision, issued 29 April 2026. Other report references remain available. This assignment supplies report navigation and does not change ratings, installation requirements or calculations.

Trafalgar FRSS and FRSS Screw Fixed are excluded from public browsing, details, exports and new selections. Retained project IDs resolve as missing references without rewriting saved metadata. Their imported evidence remains available for recovery and existing source identities remain stable.

Family decisions require an explicit Trafalgar manufacturer and a whole normalized System Products value. Incidental mentions in titles or installation prose do not classify another product. Tests cover family boundaries, source/review preservation, exports, reference resolution and a native browser journey with invented records. Run `npm run test:fyreshield-reports-browser` for that journey.
