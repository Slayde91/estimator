    Button symbols, functions and shortcuts
    
        
    Search by name, symbol, function or shortcut. Drawing shortcuts work in Takeoffs when the control is available, focus is outside text fields and no dialog is open. Ctrl/Cmd accepts Control or Command; other Ctrl shortcuts use Control.
    
        
    
        
    
        
    
      
    
      
    
        
    Start a project
    1. Open Estimates and enter the project number, client and site address.
    2. Enter the job quantities, crews, products and allowances that apply.
    3. Open Calculators for a specialist workbook calculator. Use Estimates for Main and Calculators for Firestopping.
    4. Review the Estimate Summary and both breakdowns.
    5. Use Save the first time. Use Save after the file has a location.
    
        
    Build the Quote
    Quote combines materials, labour, access, travel and adjustments. The summary updates after valid changes. Choose a section tab to edit or audit its values.
    In Material Requirements & Output, the copy symbol duplicates a work-item row. A duplicate has the same inputs and labour team as its source. Its material and labour are added to the summary and breakdowns. Use its trash symbol to remove it.
    
        
    Firestopping
    Open Calculators, then choose Firestopping. Complete the item tabs, review Item Summary and Item Breakdown, and use the plus symbol to add the item to the Firestopping Schedule.
    The schedule shown below the item is the same schedule shown in Quote. Edit, remove, undo or recalculate in either location. Only scheduled items contribute to quote totals. Open Document in Main to download the Breakdown PDF or the complete current Firestopping Schedule as XLSX or PDF. Use Document in the current item to download that item’s details; its PDF also includes the source diagram when attached.
    
        
    Product Calculators
    Choose Steel Spray, Steel Board or Ductwork under Calculators. Move through the page tabs, enter values in the input fields and select Recalculate. Open Document and choose Export XLSX Template for the supported import layout for the selected calculator.
    The page owns vertical scrolling. Wide tables scroll sideways without changing height when a field is selected.
    
        
    Schedules and files
    Schedule tabs let you add, duplicate, remove and undo rows. Import XLSX replaces the current schedule draft only after confirmation. Export Template provides the supported input layout.
    The Document menu lists imports, templates and downloads for the current schedule or summary, with an icon and name for each action. A generated file reflects the values captured when the action began.
    
        
    Pricing Library
    Main Library edits the shared prices used by new work. Current Project edits only the open project’s pricing snapshot. Main Estimator and Firestopping Estimator availability groups control where a product or service appears.
    Export Excel includes the whole draft library. Import the complete workbook, review the comparison, then save or apply it. Discard returns to the last saved or applied values. Reset loads application defaults into the draft and still requires Save or Apply.
    
        
    Firestopping and Technical Libraries
    Firestopping Library records store reusable item inputs, calculated prices and source diagrams. Technical Library records store supporting system and report references. Use the link symbol to associate one or more records and the trash symbol to unlink an association.
    Editing or unlinking a library record does not edit the source technical document. Reusable library data does not itself confirm project suitability, compliance or approval.
    
        
    Save, load and attach files
    A project file contains the Quote, duplicated work items, Firestopping Schedule, calculator drafts and the project’s pricing snapshot. Save chooses a location for a new project and safely updates an already selected file.
    After saving, Project files can store attachments beside the project. Projects searches the linked folder and subfolders. Opening a file replaces the current drafts only after confirmation.
    
        
    Older prices and recalculation
    Loaded projects keep their saved pricing so historical totals do not silently change. Use current pricing deliberately replaces that snapshot and recalculates the project with the current Main Library.
    If a product or crew is missing, select a valid replacement before saving or exporting. Unsaved pricing changes remain separate until Save pricing or Apply is used.
    
        
    Messages and recovery
    • Select Teams: choose a crew for each used work-item type.
    • Check inputs: correct the field marked in red, then recalculate.
    • Unsaved changes: use Save before closing or replacing the project.
    • Saved pricing snapshot: the project is intentionally using its own frozen prices.
    • If an import is wrong, cancel the review or discard the draft before saving it.
    

        
    Final review
    • Check project identity, measured quantities and assumptions.
    • Confirm products, yields, rates, crews, wastage and adjustments.
    • Review Estimate Summary, Material Breakdown, Labour Breakdown and Firestopping Breakdown.
    • Resolve all warnings and calculation errors.
    • Save the project and review the exported file.
    • Confirm technical suitability and fire-rating requirements with the manufacturer and relevant project authority.
