Using the Ceasefire Estimator
A plain-English guide to finding your way around and producing an estimate.

      

        
Start here
  1. Open Estimator and enter the project details.
  2. Choose the main Estimator for project quantities, or Firestopping Estimator for penetration items.
  3. Review the totals and breakdowns before saving or downloading a report.
  4. Use Save As the first time. After that, use Save to update the same project file.

        
Estimator
The main Estimator calculates material quantities, labour and project costs from the values you enter. Expand a breakdown when you need to check how a total was built.
The Firestopping Estimator calculates one item at a time. Review its Item Summary, add the item to the schedule, then recalculate the schedule to update project totals.

        
Libraries
The Pricing Library holds product, service, yield and rate information used by estimates. Review imported changes before saving them.
The Firestopping and Technical Libraries hold reusable firestopping records and their supporting technical references. A library record helps you reuse data; it does not confirm that a system is suitable for a project.

        
Calculators
Choose a calculator, move between its pages, enter the required values and select Recalculate. Red messages need attention before you rely on the result.
You can export schedules and summaries to PDF or Excel. Imported Excel schedules replace the current calculator draft after you confirm the change.

        
Saved Projects
Link a project folder to browse files saved from this application. Opening a project restores its estimates, calculator drafts and saved pricing snapshot.
If a saved project uses older prices, the application tells you. Choose current pricing only when you want to recalculate with today’s library.

        
Before you finish
  • Check project details, quantities, products, rates and assumptions.
  • Resolve visible calculation errors.
  • Save the project before closing the application.
  • Treat results as an estimating guide and confirm technical suitability with the manufacturer and relevant project authority.
