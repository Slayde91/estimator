Google Maps setup

Driving distance and travel time

The project map link works without an API key. Driving estimates inside CLASSIFIRE need a Google Maps Platform account with billing and the Routes API enabled.

  1. Open the Google Routes setup guide. Enable Routes API, review pricing and set a quota suitable for your usage.
  2. Create a server API key restricted to Routes API. Use an IP restriction appropriate to the computer or server making the request. Do not put the key into project files or browser code.
  3. Close the running estimator server. On the computer running CLASSIFIRE, set the CEASEFIRE_GOOGLE_MAPS_API_KEY environment variable before starting the app again. Your administrator can make this available to the application account.
  4. In Settings, choose “Refresh Google Maps status”. Then open Access & Travel, enter your current address or use your current location, and choose “Check driving route”.

The key stays on the application server. A lookup sends your selected current location and project address to Google. Locations and route results are temporary and never alter the quote's travel charges.
